21. Character Set & Collation

Admin & Internals

Character Sets and Collations

A Character Set defines the encoding used to store physical text (e.g., mapping the letter 'A' to binary). A Collation defines the mathematical rules for comparing and sorting those characters (e.g., does 'a' equal 'A'?).

The utf8mb4 Standard

In MySQL 8.0, the default character set was permanently changed to utf8mb4 with the collation utf8mb4_0900_ai_ci. Unlike older MySQL versions (where utf8 only supported 3 bytes), utf8mb4 supports the full 4-byte Unicode standard, including emojis.

The Cascading Defaults Rule

What is the default character set when a table is created? There is no single answer. MySQL resolves it through a strict hierarchy of cascading defaults:

  1. Server Default: Defined in the MySQL configuration (my.cnf). If you run CREATE DATABASE db; without specifying a charset, it inherits the Server Default.
  2. Database Default: If you run CREATE TABLE users; without specifying a charset, the table inherits the Database Default.
  3. Table Default: If you add a column email VARCHAR(50) without specifying a charset, it inherits the Table Default.
  4. Column Definition: You can explicitly override everything at the column level: email VARCHAR(50) CHARACTER SET latin1.
