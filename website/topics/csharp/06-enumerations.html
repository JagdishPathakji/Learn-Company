Enumerations (Enums)

Difficulty: Beginner | Category: C# Fundamentals

The Beginner's Mental Model

Imagine filling out a web form. Some fields are open text boxes (like "Name"), where you can type anything. Other fields are Drop-down Menus (like "Country"), where you are forced to pick from a predefined, strict list of options.

In C#, an Enum (Enumeration) is exactly that: a drop-down menu for your code. It restricts a variable to only accept specific, predefined values, preventing developers from typing invalid data.

A. The Core Problem: "Magic Numbers"

In older codebases, developers used "Magic Numbers" to represent statuses. For example, in a database, the `ROLE` table might define:

  • 1 = Admin
  • 2 = Editor
  • 3 = Author

A junior developer writing a security check might write: if (userRole == 2) { ... }. This is terrible practice. Six months later, nobody remembers what 2 means. If someone accidentally types if (userRole == 99), the compiler won't complain because 99 is a valid integer, but the application will break because role 99 doesn't exist.

B. De-Jargoning the Enum (Step 1)

1. Enum (Enumeration) A custom Data Type you create that holds a fixed set of named constants. Behind the scenes, the computer still sees them as integers (0, 1, 2...), but the developer sees readable English words.
2. Casting The act of forcing a raw Integer (from a database) to become an Enum, or forcing an Enum back into an Integer (to save to a database).
3. Validation (Enum.IsDefined) A built-in C# tool to check if a random number (like 99) actually exists in your drop-down menu before you try to use it.

H. Knowledge Base Project Integration

Let's map this directly to your actual schema. In your user_tables.sql, you have a USER_ROLE table that maps a user_id to a role_id (an integer). Let's build the C# Enums and Services to handle this safely.

COMPLETE EXAMPLE 1: Basic (Defining and Using Enums)

An Enum is just a list of named options. It replaces confusing magic numbers with highly readable English words.

C# - Basic Enum
using System;

namespace KnowledgeBase.Simple
{
    /// <summary>
    /// Defines the access level and permissions of a user in the system.
    /// </summary>
    public enum EnmUserRole
    {
        Reader,
        Author,
        Admin
    }

    class Program
    {
        static void Main()
        {
            // Assign a value using plain English
            EnmUserRole currentRole = EnmUserRole.Author;
            
            Console.WriteLine("My current role is: " + currentRole);
        }
    }
}
Console Output:
My current role is: Author

COMPLETE EXAMPLE 2: Intermediate (Enums and Databases)

Databases usually store Enums as Integers (numbers) to save space. C# makes it incredibly easy to convert between the English word and the Integer value using Casting.

C# - Casting Enums
using System;

namespace KnowledgeBase.Simple
{
    /// <summary>
    /// Represents the publication lifecycle of an article.
    /// </summary>
    public enum EnmArticleStatus
    {
        Draft = 1,
        Published = 2,
        Archived = 3
    }

    class Program
    {
        static void Main()
        {
            EnmArticleStatus currentStatus = EnmArticleStatus.Published;

            // 1. Convert Enum to Integer (For saving to Database)
            int databaseValue = (int)currentStatus;
            Console.WriteLine("Number saved to DB: " + databaseValue);

            // 2. Convert Integer back to Enum (When reading from Database)
            int numberFromDatabase = 3;
            EnmArticleStatus loadedStatus = (EnmArticleStatus)numberFromDatabase;
            Console.WriteLine("Status loaded from DB: " + loadedStatus);
        }
    }
}
Console Output:
Number saved to DB: 2
Status loaded from DB: Archived

COMPLETE EXAMPLE 3: Advanced (Switch Statements)

The most powerful way to use an Enum is inside a switch statement. This allows you to easily route logic based on the status, completely avoiding messy if/else chains.

C# - Enum Switch Statement
using System;

namespace KnowledgeBase.Simple
{
    /// <summary>
    /// Defines the access level and permissions of a user in the system.
    /// </summary>
    public enum EnmUserRole 
    { 
        Reader, 
        Author, 
        Admin 
    }

    class Program
    {
        static void Main()
        {
            EnmUserRole activeRole = EnmUserRole.Author;

            // The switch statement checks every possible option cleanly
            switch (activeRole)
            {
                case EnmUserRole.Reader:
                    Console.WriteLine("You can only read articles.");
                    break;
                case EnmUserRole.Author:
                    Console.WriteLine("You can read and write articles.");
                    break;
                case EnmUserRole.Admin:
                    Console.WriteLine("You have full system access.");
                    break;
                default:
                    Console.WriteLine("Unknown role.");
                    break;
            }
        }
    }
}
Console Output:
You can read and write articles.
